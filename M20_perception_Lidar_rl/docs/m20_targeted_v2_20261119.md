## 已落实的修改

### 1. 全 Actor 参与学习，教师仅提供选择性参考

`v111_targeted_v2_runner.py` 解除父类对 `mlp.0.*`、`mlp.2.*` 和 `distribution.*` 的冻结。所有 Actor 参数均 `requires_grad=True`，并且都在 Adam 参数组中；Critic 继续学习，教师参数保持固定。

保留现有分场景教师约束：前腿上楼摆动权重 0.04、后腿 0.35；移动共同驱动保留，楼梯轮间差动为 0.08；直行 hipx、严格静止接管轮速已有的定向放宽保留。因此允许重学错误步态，并继续给可靠的基础运动提供参考。它是软约束，不能保证长训永不退化。

### 2. 让探索可学习，同时防止方差塌缩

腿动作标准差下限为 0.18，轮动作为 0.35，均为原始动作单位。每次 Adam 更新之后投影到下限，加载低标准差权重后的下一次 rollout 采样前也执行该检查；下限以上的标准差继续学习。0.02 系数的辅助项提供下限方向的梯度，`Loss/targeted_extra` 记录该项；已在下限以上时为零是正常现象。

新增 `Loss/exploration_leg_std_min`、`Loss/exploration_wheel_std_min` 诊断。该下限保护训练探索，不能单独保证策略均值会前进，也不改变部署时使用的确定性均值。

### 3. 将落脚大部分信用保留给真正承重

每前轮、每物理目标仍最多获得 1 单位落脚信用，奖励权重保持 0.30。V2 中无接触下降最多获得 0.15，剩余至少 0.85 必须靠目标踏面附近的实际加载：垂向力超过 15 N 开始贡献，45 N 达到加载饱和，并要求轮底距目标平面不超过 0.035 m。旧 V1 默认的 0.5/5 N 行为保留。

保持、回退、关闭命令后再打开、reset 不重复支付同一信用。B1 稳定支撑 2.5、后续逐阶稳定支撑 1.6，以及连续 3 帧的支撑认定保持不变；短促碰一下不能替代稳定支撑。V2 的 reset/课程统计调用相同的承重函数，避免统计先调用时误用 V1 参数。

### 4. 用独立正收益保留前进机会

原生速度跟踪、世界前进、速度不足项及机身/后轮进度继续独立存在。额外增加上楼世界路线速度正奖励，最大为 0.75/秒，到命令速度的 80% 达到本项饱和；原生完整速度目标继续存在，80% 不构成限速。

新增奖励只在 B1 减速区之后、真实上楼 flight 内且无明显侧移/转向命令时生效。停着不动、向后运动、零命令、非上楼地形不获得该收益；发生过漏阶也不抹掉后续前进收益。显式侧移与转向继续沿用原生目标。没有增加上楼动作幅度惩罚或全楼梯减速要求。

这与有限越阶事件预算、选择性教师参考和探索保底共同降低“少动少错”的诱因。不能把这些措施解释为数学上保证不退化，仍须并列观察实际速度、到顶、逐阶、跌倒和停滞。

### 5. 保留现有平地、偏航和降噪修复

保留镜像一致性 0.05、严格静止接管轮速 0.10、真实平地回放的目标工作空间 0.03；降噪仍采用均值快速反向正则（上限系数 0.02）和触地/载荷突变成本（最多 0.15/秒，200～1200 更新预热）。没有用整段降低速度来换取降噪表现。声学代理仍需实际速度匹配后比较，未获得真实声压/dBA 改善证据。

在仓库内训练子目录运行。初始化路径显式指定，避免与旧 run 名里的 `from43800` 混淆：

```bash

  --output artifacts/targeted_v2_30000_from45100_manual_20261119
```
