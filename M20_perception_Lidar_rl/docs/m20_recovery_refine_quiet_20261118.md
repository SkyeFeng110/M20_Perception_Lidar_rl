# 2026-11-18：剩余问题、细化修复与声学降噪接入

本次按用户最新请求同时实现行为修复和降噪训练能力。参考的是另一对话已保存到仓库的[降噪研究](m20_stair_acoustic_noise_literature_20261117.md)及根目录问答纪要；不是直接读取另一个聊天窗口。旧文档里“先完成行为、再做降噪”的顺序已被本次请求更新。

本次没有启动 PPO、拟合模型、修改历史权重或恢复已停止的训练。新增的是可手动启动的独立任务 `M20-Stair-V11.1-RecoveryRefine-v0`，不是已经训练完成的低噪声模型。

停止的会话是 `artifacts/recovery_4096_20261117_145846_170996876`；最后完整评测为追加 8500 更新、`model_43800.pt`。85 次评测中，每次均有 8/8 上楼案例到顶，没有跌倒、停滞或绕行，但没有一次通过最终修复条件。

| Z→C→8 平地，伸展 p95 | 0.2868 m | 0.1439 m | 有改善，仍高于 0.07 m 目标 |

## 2. 改善不足的原因与对应改动

这些机制由代码与轨迹支持，但没有通过消融实验确定某个机制是唯一根因。

1. **优化目标更容易奖励到顶，而逐阶接触反馈稀疏。** 原配置有真实前进收益和每阶稳定支撑事件，但没有接近正确下一踏面的持续正向提示；漏阶会让严格完整奖励不可达。原代码已经允许漏阶后重新同步、领取后续支撑奖励，不能误说成“漏一次就再无支撑奖励”。新任务加入每个目标踏面最多 0.2/轮的有限接近信用，以及 0.5 的真实四轮到顶事件；原来的稳定支撑、跳阶历史及严格完整奖励保留。保持不动、后退重走或悬空穿过目标不能反复刷取信用。
2. **平地质量奖励在姿态和偏航同时不好时趋近零。** 原来把 `exp(-姿态成本-直行误差)` 相乘，容易让一个问题淹没另一个问题的反馈。改为独立的有理函数质量项；仍然要求实际沿命令方向前进，且只作为基础速度收益之外的加分。
3. **训练缺少部署接管后的停留→前进过程。** 原楼梯命令最后被强制为正向速度，平地虽有静止样本，也没有固定的两秒停留后斜坡起步。新任务用 25% 环境提供标称站立接管、零命令 2 秒、0.6 秒斜坡至 0.5～1.0 m/s；75% 保留原随机化和命令采样。这覆盖 C→8 的重要环节，并不等于把外部 Z 起身控制器完整搬入 Isaac。真实 Z→C→8 继续通过 MuJoCo 原流程评测。
4. **瞬时角速度好看，不代表航向没有累积误差。** 新任务对零侧移/零转向命令加入相对本段起点的航向与路线侧移成本，上限 0.2/秒；不向部署命令偷偷注入转向修正。仅起步前偏了约 9.5°，走 8 m 就可能带来约 1.3 m 横移，说明应同时修复静止接管和前进阶段。
5. **教师在需要修复的动作方向上仍有约束。** 旧楼梯锚定只在 Actor 看见正级高时放宽腿部，且四轮差动仍较强。新任务按 replay 的真实楼梯场景标签覆盖静止/接近阶段，放宽矢状面关节及轮速差动的错误继承，同时继续锚定共同驱动与其他稳定动作。教师仍是原始 35300，不把失败候选冒充成功教师。
6. **训练统计和固定测评统计不一致。** 原训练姿态等指标常取 episode 重置时的当前值；它们不等价于 MuJoCo 行驶窗口的 p95、累计偏航或逐阶序列。新任务补充 episode 统计，并把每次固定案例的原始行为指标直接写入 TensorBoard。

固定 63D Actor 没有新增绝对航向/路线误差观测。新增奖励可促进对称驱动、减少自身偏置，但不能据此承诺它具备任意外扰后的绝对航向闭环保持能力。

## 3. 已实现的降噪训练能力

目标是实际触地声和电机/传动啸叫，不是调低传感器观测噪声。

- **触地冲击代理：** 四轮分别使用 15 N 接触开启、5 N 释放的迟滞，至少离地 0.06 秒才产生新触地事件；计算触地前法向接近速度和触地后 0.06 秒内的正载荷突变。初始静态载荷、重置瞬移和持续承重不计触地成本。新增接触成本最多 0.15 回报/秒。
- **电机动作代理：** PPO 在同一段 rollout 的三个连续观测上计算确定性策略均值，约束超过死区的快速反向；跳过跨 episode 的三帧组合，楼梯矢状面动作给予 0.2 系数。单调抬腿、持续轮速和正常加速没有动作幅度成本。正则最大系数为 0.02；这个系数是优化器损失单位，不能与每秒奖励上限混为一谈。
- **探索与声学问题分开：** 原固定高斯探索方差保留；不直接把采样动作反向成本加进回报，避免把无法消除的探索随机量收费后诱导少动。环境中的实际动作反向量仍记录作诊断。
- **渐进接入：** 新阶段前 200 更新降噪系数为零，200～1200 更新线性升到全部强度。计数相对新目标开始，避免恢复 35300/43800 的历史步数后立即满强度。普通 `--resume` 会保留此阶段计数；`--initial-checkpoint` 开始新目标并清空 Adam 状态。
- **执行接口保留：** Actor 为 63→512→256→128→16 ELU，critic 为 568D；没有增加输出、低通滤波、可变 PD 或 PWM 改动。只允许原 B1 局部减速，不改变后续楼梯速度目标。

Isaac 训练用轮底法向的竖直分量和竖直合力近似水平踏面接触，控制频率为 50 Hz，不能完整捕捉所有 1 ms 冲击峰值。MuJoCo 补充记录按 1 ms 物理步测量真实接触法向、接触点速度（包含 `omega × radius`）、短时载荷建立、关节转速、转矩变化和动作反向。正常滚动的轮心前进不会被当成滑移；滑移只作诊断。

这些都是机械代理量。持续滚动噪声、驱动电磁谐波、齿轮/结构共振及材料声学还需要实机音频和电流记录；目前没有声压校准或 dBA 减少的证据。

## 4. 防止再次“少动少错”

基础速度跟踪、世界路线进度和不足速度成本完全保留，不乘姿态/安静系数；B1 以外不新增速度上限。旧平地新增负项上限 1.5/秒，加路线 0.2、接触 0.15，共 1.85/秒；在固定 0.5/0.7/1.0 m/s 测评速度上，小于单独基础速度项从静止到匹配速度的收益。另有真实前进、稳定支撑和完成收益。

这只是新增奖励部分的预算检查，不是整个 PPO 收敛或长期不退化的数学保证。均值反向正则也保持小系数和楼梯动作豁免，后续必须一起看速度、支撑与噪声代理。

有效的行为失败继续保存和记录，**不会停止、回滚或重置优化器**。跌倒、停滞、丢失上楼能力也没有重新变成停止条件；运行异常、无效证据、资源不足及用户中断仍停止。

## 5. 验证与新测量

结果位于 `artifacts/refine_validation_20261118/`。

- CPU 回归覆盖奖励预算、落点信用防刷、接触迟滞/重置、必要抬腿、真实 RSL 构造与均值正则反传、跨 episode 过滤、参考梯度、行为失败继续及 ABI。
- Isaac 冻结策略测试：40 环境、180 控制步；接管样本实际进入前进，奖励有限，原生速度项与旧任务相同，Actor/critic ABI 相同，模型权重未更新、Adam 无状态。最终结果见 `isaac_runtime_v2.json`。早期测试的 Kit 退出等待问题已在探针中修复，未涉及训练。
- 原始 35300 和停止时 43800 各重测原有 12 案例：新增测量前后，各自的旧行为字段没有变化，见 `instrumentation_parity.json`、`latest_instrumentation_parity.json`。43800 依然是未通过修复/保留的旧候选，不能当成新方案训练成果。
- 两个模型分别补测 0.26/0.30 m 踏深、0.5/0.7 m/s 的四个下楼案例，均完成几何终点、无跌倒；它是补充证据，不并入原 12 案例的通过数。
- 新数据：Z→C→8 上楼、0.26 m 踏深、0.7 指令的接近速度 RMS，35300 为 1.456 m/s，43800 为 1.679 m/s，但后续路线速度也提高约 13.6%，**不满足实际速度 ±5% 匹配，不据此认定降噪退化/改善**。
- Z→C→8 平地实际速度匹配，43800 的腿动作反向 RMS 约为原来的 10.9%，轮约 5.1%，但偏航/伸展仍未达标。动作更平滑显然不能单独解决当前行为问题，也不能证明声压降低。

仪器记录、测试代码和配置检查通过，不能替代下一阶段真正训练后的收益比较。

## 6. 手动启动

从仓库根目录进入训练根目录后，执行以下命令。细化任务默认从已停止会话的 `model_43800.pt` 开始；冻结参考教师仍是原始 `model_35300.pt`，不会把 43800 当教师。

```bash
cd /home/arcus/deeprobotics_m20_rl/M20_Perception_Lidar_RL/M20_perception_Lidar_rl
M20_PYTHON=/home/arcus/miniconda3/envs/isaaclab/bin/python \
  scripts/train_m20_v111_guarded.sh --refine \
  --num_envs 4096 --total-updates 30000 --segment-updates 100 \
  --baseline-results data/m20_recovery/baseline_v2/results_with_acoustic_proxies.json \
  --output artifacts/refine_quiet_30000_20261118
```

这是**从 43800 继续初始化、再追加 30000 次 PPO 更新**，每 100 次测评。`--output` 必须为没有旧 `status.json` 的新会话目录；不会自动重启已停止的会话。也可追加 `--initial-checkpoint /绝对路径/model_N.pt`，明确改用其他保留候选，教师仍是 35300。`--check-only` 只检查输入、模型/回放 ABI 和资源配置，不启动模拟器或 PPO；本次已执行。

迁移时若不携带本次 artifacts，可先用已有原始权重重新采集代理基线：

```bash
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 \
  /home/arcus/miniconda3/envs/isaaclab/bin/python scripts/tools/m20_repair_acceptance.py \
  --checkpoint interview_prep/model_35300.pt --baseline-only \
  --output artifacts/original_noise_baseline_new
```

`data/m20_recovery/baseline_v2/results_with_acoustic_proxies.json` 是本次复测的可携带基线，包含固定 12 案例与机械代理；旧的 `results.json` 仍保留，程序会明确标为没有代理基线，不编造零值或下降比例。
